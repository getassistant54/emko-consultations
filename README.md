# 📅 ЁМКО: Запись на онлайн-консультации (WordPress Plugin & Integration Hub)

Комплексное решение для автоматизации записи на консультации для анимационной школы **ЁМКО**:
- 🔗 **Связка сервисов:** WordPress + Яндекс Календарь (CalDAV) + Яндекс Телемост + GetCourse (Deals API).
- 💰 **Стоимость содержания:** **0 рублей/месяц** (без сторонних сервисов записи и без платных тарифов Яндекс 360).
- 🔄 **GitHub репозиторий:** `getassistant54/emko-consultations`

## ⚙️ Как работает цепочка процессов

1. **Оплата на GetCourse:**
   - Ученик покупает консультацию ➔ GetCourse создает сделку со статусом «Оплачен» и допполем `Статус консультации = "Не записан"`.
   - Процесс GetCourse отправляет **Письмо №1**:  
     `https://vash-sait.ru/booking/?deal_id={order_id}&name={first_name}&email={email}&phone={phone}`
2. **Выбор слота на сайте WordPress:**
   - На странице сайта размещен шорткод `[emko_booking]`.
   - Виджет подтягивает занятость из Яндекс Календаря преподавателя через CalDAV.
   - Ученик видит время в двух таймзонах: **МСК + своё местное**.
3. **Фиксация записи:**
   - Плагин создает уникальную встречу в **Яндекс Календаре** и генерирует персональную ссылку на **Яндекс Телемост**.
   - Добавляет email ученика в `ATTENDEE` (Яндекс сам отправляет красивое приглашение на почту).
   - Плагин вызывает **GetCourse Deals API** и записывает в сделку:
     - `Дата и время консультации` = выбранный слот;
     - `Преподаватель` = имя преподавателя;
     - `Ссылка на Телемост` = ссылка видеовстречи;
     - `Статус консультации` = `Записан`.
4. **Уведомления в GetCourse:**
   - Статус `Записан` ➔ отправка **Письма №2** с подтверждением и ссылкой на звонок.
   - За 1 час до встречи: cron ставит статус `Напомнить` ➔ отправка **Письма №3** (напоминание).
   - Через 2 часа после встречи: процесс шлет **Письмо №4** для контроля качества.
